# Aurora

> A creative static frontend project exploring visual atmosphere and responsive composition.

[![Live Demo](https://img.shields.io/badge/Live_Demo-Explore-21C7E8?style=for-the-badge&logo=netlify&logoColor=white)](https://aurorasphere.netlify.app/)

## Overview

**Aurora** is a frontend practice project created to experiment with a more expressive visual direction while strengthening responsive layout skills.

Rather than focusing on backend functionality, the project concentrates on how spacing, section composition and styling can make a static website feel more intentional and engaging.

## Highlights

- Creative landing-page direction
- Responsive layout
- Clean section composition
- Modern visual styling
- Lightweight static frontend implementation
